## 🎭 Aperçu du Design

### Style Manga/Anime
- **Couleurs** : Noir & Blanc (#050505 / #F0F0F0)
- **Police** : Oswald (uppercase, tracking-wide)
- **Effets** : Smooth scroll, parallax, text-outline
- **Animation** : Framer Motion

### Comparaison Avant/Après

#### AVANT (Cyberpunk)
- Néons cyan/violet
- Effets glitch
- Particules et pluie
- Style futuriste

#### APRÈS (Manga)
- Minimaliste noir/blanc
- Bordures fines
- Animations fluides
- Style épuré

## 🆘 Problèmes Fréquents

### Le site ne s'affiche pas
```bash
# Vérifier que node_modules existe
ls node_modules/

# Si absent, installer :
npm install
```

### Erreur "module not found"
```bash
# Réinstaller les dépendances
rm -rf node_modules
npm install
```

### Le smooth scroll ne fonctionne pas
→ Rafraîchir la page (Cmd+R ou Ctrl+R)

### Les animations sont lentes
→ Vérifier les performances dans l'onglet DevTools
